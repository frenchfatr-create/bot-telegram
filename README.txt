# 📘 Инструкция по настройке и запуску бота-предложки

Этот бот позволяет подписчикам присылать видео, новости, фото и кругляшки прямо боту в личные сообщения. Бот мгновенно пересылает оригинальное сообщение в вашу группу администраторов, прикрепляя кнопки **[ ✅ Да (В канал) ]** и **[ ❌ Нет (Отклонить) ]**.

* При нажатии **«✅ Да»** сообщение автоматически выкладывается в ваш Telegram-канал (или сразу в несколько каналов)!
* При нажатии **«❌ Нет»** сообщение отклоняется и в канал не попадает.

---

## 📋 Шаг 1. Создание бота в @BotFather (получение токена)

1. Откройте в Telegram официального бота: **[@BotFather](https://t.me/BotFather)**.
2. Отправьте команду: `/newbot`
3. Введите название бота (например: *Предложка Ялта*).
4. Введите юзернейм на английском с окончанием `bot` (например: *krum_yalta_bot*).
5. Скопируйте полученный **токен** вида:  
   `1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ`

---

## 🔓 Шаг 2. Настройка доступа к сообщениям в @BotFather (ОБЯЗАТЕЛЬНО!)

По умолчанию Telegram скрывает часть сообщений в группах от ботов (включен режим приватности). Чтобы бот корректно видел команды и работал в админ-группе, **отключите режим приватности**:

1. В чате с **[@BotFather](https://t.me/BotFather)** отправьте команду:
   `/setprivacy`
2. Выберите вашего бота из предложенного списка (нажмите на кнопку с его именем).
3. Нажмите кнопку **«Disable»** (или **«Turn off»**).
4. BotFather ответит:  
   *«Success! The new value is: 'DISABLED'. Note that status changes take a few minutes to take effect.»*

> 💡 **Также проверьте доступ к добавлению в группы:**
> Отправьте в @BotFather команду `/setjoingroups` ➡️ выберите бота ➡️ выберите **«Enable»** (разрешить добавление в группы).

---

## 📢 Шаг 3. Добавление бота в канал(ы)

1. Зайдите в ваш Telegram-канал, куда бот должен выкладывать одобренные посты.
2. Перейдите: **Управление каналом** ➡️ **Администраторы** ➡️ **Добавить администратора**.
3. Найдите вашего бота по его юзернейму (например `@krum_yalta_bot`) и добавьте.
4. Включите право: **«Публикация сообщений»** (*Post messages*).
5. Нажмите **«Сохранить»**.

*(Если каналов несколько — добавьте бота администратором в каждый из них).*

---

## 👥 Шаг 4. Настройка группы администраторов

1. Создайте группу в Telegram (или откройте существующий чат администраторов).
2. Добавьте созданного бота в эту группу и сделайте его **Администратором**.
3. **Как узнать точный ID группы:**
   * Просто напишите прямо в группу команду: `/id`
   * Бот мгновенно ответит сообщением с точным ID вашей группы (он всегда с минусом `-100...`, например `-1001987654321`).
   * Скопируйте этот ID.

---

## ⚙️ Шаг 5. Настройка файла конфигурации (.env)

В папке с ботом откройте файл **`.env`** через обычный **Блокнот**:

```env
# Токен бота от @BotFather (из Шага 1)
BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ

# Канал для выкладки (или несколько каналов через запятую):
# Пример для 1 канала: CHANNELS=@KrumYalta
# Пример для 2 каналов: CHANNELS=@KrumYalta, @CrimeaNews
CHANNELS=@KrumYalta

# ID группы администраторов из Шага 4 (обязательно с минусом -100...):
ADMIN_CHAT_ID=-1001987654321

# База данных (оставьте по умолчанию)
DATABASE_PATH=database.sqlite
```
Сохраните файл (`Ctrl + S`).

---

## 🚀 Шаг 6. Запуск бота (в 1 клик на компьютере)

1. Убедитесь, что на компьютере установлен **Python 3.10+** с официального сайта [python.org](https://www.python.org/) *(при установке обязательно поставьте галочку «Add Python to PATH»)*.
2. При первом запуске запустите файл **`install_requirements.bat`** (установит нужные библиотеки за несколько секунд).
3. **Для запуска бота:** дважды кликните по **`start_bot.bat`**.  
   *Появится окно консоли с зеленой надписью о том, что бот успешно подключен. Просто сверните это окно вниз — бот будет работать 24/7!*

---

## 🎮 Как работает бот в реальной жизни:
1. Подписчик заходит в личные сообщения бота и присылает видео, фото или текст.
2. Бот мгновенно пересылает оригинальное сообщение в группу админов и прикрепляет кнопки:
   * **[ ✅ Да (В канал) ]**
   * **[ ❌ Нет (Отклонить) ]**
3. Любой админ нажимает `✅ Да` ➡️ бот сразу выкладывает пост в канал, а на сообщении в группе фиксируется: `[ ✅ Опубликовано (@username_админа) ]`.
4. Если админ нажимает `❌ Нет` ➡️ пост никуда не публикуется, кнопка меняется на `[ ❌ Отклонено (@username_админа) ]`.
